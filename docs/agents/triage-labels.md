# 分流标签

技能使用五个 canonical role。本表将它们映射到本仓库实际使用的中文标签。

| canonical role | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `需要分流` | 等待维护者评估 |
| `needs-info` | `需要补充信息` | 等待提交者补充信息 |
| `ready-for-agent` | `可交给代理` | 信息完整，可以交给代理处理 |
| `ready-for-human` | `待人工处理` | 需要人工实施 |
| `wontfix` | `不处理` | 不会处理此问题 |

当技能提到某个 canonical role 时，使用对应的中文标签字符串。
