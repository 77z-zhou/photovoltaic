# 领域文档

这是工程技能探索本仓库领域知识时应遵循的文档规则。

## 开始探索前读取

- 如果存在，读取根目录的 `CONTEXT.md`。
- 读取与当前工作区域相关的 `docs/adr/` 中的 ADR。

如果这些文件不存在，静默继续，不要仅因为缺失就提示或建议立即创建。领域术语或决策真正确定时，由 `/domain-modeling` 技能按需创建。

## 文件布局

本仓库采用 single-context 布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 使用术语表

在问题标题、重构提案和测试名称中命名领域概念时，使用 `CONTEXT.md` 中定义的术语。如果术语表中没有所需概念，先判断是否误用了项目未采用的同义词；如果不是，则记录为 `/domain-modeling` 的待解决缺口。

## 标记 ADR 冲突

如果输出与已有 ADR 冲突，应明确指出，不要静默覆盖。例如：

> 与 ADR-0007 冲突，但值得重新讨论，因为……
