# 采用领域所有权与版本化 REST 契约

核心领域模块拥有各自对象的状态和不变量：项目模块负责项目状态转移，账单模块负责账单生成、调整和结清判断，合同模块负责合同版本和签署状态，其余模块通过明确的 Interface 协作。三端通过同一套版本化 REST API 访问业务能力，API 使用 OpenAPI 描述并按角色裁剪返回数据。

业务数据使用关系表和外键；供应商原始报文与可变扩展字段放在隔离的 JSONB/原文记录中，不让供应商字段渗透核心模型。关键写操作在同一事务中写入业务数据和 Outbox 事件，由后台任务异步投递通知、回调处理、账单生成和报表更新。演示账号使用服务端会话/JWT，微信和支付宝登录作为独立身份 Adapter，将平台用户绑定到内部联系人。

这样可以让状态机和账单规则集中在深模块内部，避免前端或其他模块直接修改核心数据；同时保留供应商可替换性和异步回调的可靠性。
