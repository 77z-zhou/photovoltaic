# 采用最小权限与可审计的数据保护基线

平台对客户组织、联系人、项目和外部数据实行最小权限授权：按角色、组织和项目范围控制访问，敏感字段默认脱敏。人脸、征信和支付数据只保存必要的授权记录、供应商对象 ID、标准化结果和审计信息；屋顶照片、电费单、合同及验收材料存放在私有对象存储中，通过短时授权链接访问。状态、审批、合同、账单、权限和外部回调写入不可随意覆盖的审计记录，账单原件和回调原文保留版本。

演示环境以普通请求 p95 不超过 2 秒为目标，上传和外部调用异步化并可重试，错误必须向用户明确反馈。演示密钥只通过本地环境变量注入，生产环境改用密钥管理服务；密钥、证书和真实个人资料禁止进入代码仓库。系统使用结构化日志、请求/回调关联 ID、错误/任务指标和可恢复备份，留存周期与清理策略配置化。
